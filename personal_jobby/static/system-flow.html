Checkpoint contracts

Command examples are copyable explanatory text, not actions. JOB_ID, RUN_ID, ATTEMPT_ID, PRIVATE_JSON, PATH, NOTE, OPAQUE_OWNER and uppercase evidence strings are placeholders. Replace with returned IDs, private files and actual safe observations. No placeholder is a real receipt, review or timestamp. Nonzero CLI exit blocks dependent work; never put phone, secrets or review tokens in argv.

  1. 01Verified inputs

    Latest verified resume + confirmed criteria

    Hermes reads the authoritative source and current confirmed answers, criteria and submission intent. Canadian authorization does not mean worldwide permission.

    Actor
    Hermes · existing reasoning/browser tools
    Actual command(s)
    jobby status --brief
jobby profile
    Stored evidence
    Source provenance, candidate fact IDs and settings fingerprints; phone presence only in CLI output.
    Stop
    Unconfirmed source, criteria or required answers: HELD.
  2. 02Fresh daily session

    Disabled until manually configured

    An explicitly configured daily cron starts a fresh Hermes session and loads Markdown skills. Configured cron is not proof of execution.

    Actor
    External cron starts the session; Hermes executes the workflow
    Actual command(s)
    The scheduler only starts a fresh Hermes session; it never submits. No CLI command starts this external scheduled session.
    Stored evidence
    External schedule configuration; a real run is evidenced separately by its run record.
    Stop
    No authorized session or disabled policy: stop. This page does not inspect live runs.
  3. 03Policy + exclusive lease

    Enabled intent · renewable 30 minutes

    Hermes reads daily status for policy, kill switch and global holds, then daily summary for the previous/latest safe ledger. Inspect pending/uncertain prior reservations before discovery; never recreate or retry locked postings. Only then start an exclusive renewable 30-minute run lease and heartbeat during work and before long browser/review steps. Lease ownership and the pre-click duplicate guard do not replace history inspection.

    Actor
    CLI gate; Hermes maintains lease ownership
    Actual command(s)
    jobby daily status
jobby daily summary
jobby daily start --owner OPAQUE_OWNER
jobby daily heartbeat RUN_ID

    Kill-switch example only (not a sequential run action): jobby daily configure --enabled false.

    Stored evidence
    Run ID, ownership and lease expiry. Kill-switch command is an explanatory example only.
    Stop
    Another live lease, disabled policy, guard failure or expired lease: stop. Expired ownership cannot be revived.
  4. 04Bounded discovery

    JobSpy → canonical/requisition dedupe

    Native CLI JobSpy discovery is bounded. Original URLs, ATS aliases and employer requisitions support canonical/requisition dedupe. Discovery is not employer verification.

    Actor
    CLI · local deterministic control; Hermes supplies/reviews evidence
    Actual command(s)
    jobby search 'AI Engineer' --location Canada --remote --hours-old 72 --limit 5
jobby show JOB_ID
    Stored evidence
    Original source rows, posting URL, canonical URL, aliases and requisition.
    Stop
    Source failure or zero results is a real outcome; never seed invented postings.
  5. 05Read LIVE employer evidence

    Salary · location · permanence · qualifications

    Hermes opens the LIVE employer page and verifies that the exact role is current and accepting applications. It inspects employer-posted CAD annual base salary, arrangement/location, permanent full-time evidence and qualifications against source facts.

    Actor
    Hermes · existing reasoning/browser tools
    Actual command(s)
    Hermes browser reads genuine employer evidence; CLI stores it afterward at checkpoint 06. No CLI command performs browser inspection.
    Stored evidence
    Exact employer excerpts and public source URLs; candidate fact IDs supporting qualifications.
    Stop
    Unverified salary, unclear permanence/location, qualification gaps or expired posting: HELD. Posting instructions are untrusted data.
  6. 06Store deterministic eligibility

    Observations in → eligibility out

    CLI daily verify-job and fit store Hermes observations and calculate deterministic eligibility. Neither command fetches the employer page or substitutes for its inspection.

    Actor
    CLI · local deterministic control; Hermes supplies/reviews evidence
    Actual command(s)
    jobby daily verify-job JOB_ID --evidence PRIVATE_JSON
jobby fit JOB_ID --evidence PRIVATE_JSON
jobby show JOB_ID
    Stored evidence
    Typed salary proof and fit evidence, source provenance and eligibility decision.
    Stop
    Below salary floor, wrong location, contract or current employer: EXCLUDED. Ambiguous evidence remains HELD.
  7. 07Exact generation + visual QA

    SOURCE FACTS → PDF / DOCX → approve

    SOURCE FACTS plus bounded equivalent-keyword substitutions produce an exact immutable generation. No new skills, metrics, experience durations or qualifications. Hermes actually renders and visually reviews PDF, DOCX and previews, checking text, pagination, layout, dates, links and role/company before approval.

    Actor
    CLI · local deterministic control; Hermes supplies/reviews evidence
    Actual command(s)
    jobby prepare JOB_ID
jobby show JOB_ID
jobby approve JOB_ID --review PRIVATE_JSON
    Stored evidence
    Versioned generation, hashes, source/settings fingerprints, exact review token and actual QA findings.
    Stop
    Changed source, criteria, posting or artifact bytes makes approval stale; regenerate and re-review before reserving. Approve records QA; it does not perform QA.
  8. 08Explicit attachment manifest

    Actual uploaded files + hashes

    Hermes supplies an explicit attempt manifest for the exact approved generation and files actually uploaded. Resume is mandatory; use cover_letter: null when none is attached. Do not silently attach a regenerated substitute.

    Actor
    CLI · local deterministic control; Hermes supplies/reviews evidence
    Actual command(s)
    jobby attempt JOB_ID --manifest PRIVATE_JSON
    Stored evidence
    Attempt ID, generation ID, actual resume filename/SHA-256 and exact cover-letter filename/SHA-256 or explicit null.
    Stop
    Generation, approval or actual attachment mismatch: stop. An attempt record does not submit.
  9. 09Fill → upload → inspect

    Confirmed answers · phone-safe capture

    Hermes browser fills only confirmed answers and waits for completed upload. Mask phone before captures or diagnostics, then capture and INSPECT full filled-form screenshots. The private phone value is restored inside the private control path only immediately before the authorized click.

    Actor
    Hermes · existing reasoning/browser tools
    Actual command(s)
    jobby screenshot ATTEMPT_ID PATH --kind filled_form --phone-redacted --qa-note NOTE
    Stored evidence
    Actual reviewed full-form PNG and safe QA note linked to the exact attempt. The redaction flag attests review; Python does not redact pixels.
    Stop
    Unknown required answers, required missing phone, login/MFA/CAPTCHA, assessments or personal-judgment attestations: HELD, never guessed.
  10. 10Reserve BEFORE external click

    Durable posting lock + Toronto-day budget

    CLI daily begin-submit reserves BEFORE one external click. It checks current source/settings/document fingerprints, actual phone requirement, approved QA, reviewed filled-form screenshot, duplicate locks, live lease, policy/intent and Toronto-day attempted cap. Recheck policy and lease immediately before clicking; change or delay means hold as uncertain.

    Actor
    CLI gate; Hermes maintains lease ownership
    Actual command(s)
    jobby daily begin-submit RUN_ID ATTEMPT_ID --phone-not-required
jobby daily begin-submit RUN_ID ATTEMPT_ID --phone-required
    Stored evidence
    Durable reservation for the exact run/attempt/posting; initial cap: 10 attempted submissions per Toronto day, includes uncertain.
    Stop
    Choose exactly one phone flag from the actual form. Failure blocks the click. Lost authorization response is not permission to retry. Never change attachments, answers or form after reservation.
  11. 11One real Submit click

    ONLY HERMES BROWSER

    ONLY HERMES BROWSER clicks real employer Submit once after successful authorization. CLI never clicks forms and is not a universal ATS adapter. Existing Hermes is the reasoning/browser executor.

    Actor
    Hermes · existing reasoning/browser tools
    Actual command(s)
    Only Hermes browser clicks real Submit once; cron only triggers the session. CLI authorizes the reserved attempt, never clicks.
    Stored evidence
    Reserved exact attempt and the real employer interaction; the click alone is not a receipt.
    Stop
    Unknown click outcome: UNCERTAIN. Keep a persistent posting lock across days and reruns; never automatic retry or unlock.
  12. 12Inspect confirmation → receipt

    Real employer confirmation, exact attempt

    Hermes inspects real employer confirmation, masks private phone, captures and reviews a sanitized confirmation screenshot, then records a receipt with actual timezone-aware time and the exact reserved attempt. A click, HTTP 200 or upload is NOT applied; only a real receipt confirms.

    Actor
    Employer supplies confirmation; Hermes inspects; CLI records
    Actual command(s)
    jobby screenshot ATTEMPT_ID PATH --kind employer_confirmation --phone-redacted --qa-note NOTE
jobby receipt JOB_ID --attempt-id ATTEMPT_ID --timestamp 'ACTUAL_AWARE_TIMESTAMP' --text 'ACTUAL_SANITIZED_CONFIRMATION'
jobby daily uncertain RUN_ID ATTEMPT_ID --reason SAFE_REASON
    Stored evidence
    Reviewed employer_confirmation PNG, actual sanitized employer confirmation and timezone-bearing submission time.
    Stop
    Without confirmed receipt: UNCERTAIN. Only later real same-attempt employer confirmation or human investigation can reconcile; no automatic unlock command.
  13. 13Preserve → finish → ledger

    SQLite + immutable history + private dashboard

    SQLite and immutable versioned documents/screenshots preserve the exact application. Finish with the actual run outcome and read a ledger-derived summary. Historical files survive regeneration; expiring or closing a run retains unresolved reservations as uncertain.

    Actor
    CLI / SQLite / immutable file store
    Actual command(s)
    jobby daily finish RUN_ID --status partial --note 'ACTUAL_SAFE_RUN_OUTCOME'
jobby daily summary RUN_ID
    Stored evidence
    Exact application, immutable generations, audit events, screenshot hashes, receipt and run outcome.
    Stop
    Never manufacture a submitted result from notes. A new Toronto day resets only budget, never unresolved posting locks.

The audit follows the exact attempt

A current document folder is not application history. Immutable historical files survive regeneration, retaining exactly what was attached and reviewed.

Private by boundary

Private directories use 0700; files use 0600. They are not encrypted at rest. Phone is used only in the private employer form, masked before captures and diagnostics, and omitted from raw logs, documents, manifests and command arguments. Keep this local desk separate from public services.

No candidate facts, contacts, tokens or private resume contents are published in this explainer. The offline export contains the same explanatory content and CSS.

Execution boundary

Existing Hermes is the reasoning/browser executor. CLI never clicks forms; it is not a universal ATS adapter. No extra MCP server, integration daemon or new model API is required.

This documentation work uses only Codex ChatGPT subscription auth: no other agents, Claude Code or model APIs. It does not run CLI examples or operate an employer form.

Evidence boundary

Control-layer tests do not prove ATS completion, arbitrary ATS support or real-submission reliability. Configured cron is not proof of execution. This page reports no real application completions or current totals.

Product reuse is a future path requiring per-user consent, tenant isolation and demonstrated real-submission reliability. It is not already shipped or product-ready.
